# 發布資料與隱私

公開內容僅限來源清單中的程式、圖示、文件、CI 及合成測試。
執行期檔案由另一份明確清單控制。

以下資料不進入 Git、來源壓縮包或 .deb：
- 密碼、SMTP 憑證、API key、token、SSH 私鑰、憑證檔。
- 個人信箱、主機名稱、裝置序號、MAC 位址、私人掛載路徑。
- 個人設定、裝置別名、實機資料輸出、日誌、截圖、備份。
- 編輯器或助理工作紀錄、家目錄內容、既有 UPS 通知服務設定。

make privacy 檢查公開清單、檔名與常見私人資料格式，
並使用 Gitleaks 掃描內容。掃描器只輸出類別與檔名，
Gitleaks 使用 redact 隱藏命中值。這些自動檢查須搭配人工檢查，
不能保證找到所有形式的私人資訊。

首次 commit 前檢查暫存的公開檔案；push 前檢查所有將推送的 Git 紀錄，
以及實際解包的發行產物。發現敏感內容就先移除，重新建置與檢查；
不能以忽略規則掩蓋真實敏感資料。

Git 提交使用 GitHub noreply 信箱，MIT 署名使用公開帳號。
GitHub 登入使用系統憑證儲存，驗證憑證不寫進專案或遠端 URL。

一般使用不會自動截圖或上傳資料。
本機主動啟用 --capture 後，截圖可能含私人設備名稱與掛載路徑。
回報問題只提供去識別化的摘要，勿直接附上原始日誌、設定或截圖。

耗電歷史（時間、整機瓦數、不斷電系統電量與是否改用電池）只存在本機
XDG 資料目錄的 history.json（資料夾權限 0700），不上傳，也不屬於發布內容。
機型只讀取主機板廠商與產品名稱，不讀序號或 UUID；
不斷電系統只讀取 apcaccess 的狀態、數值與型號。

筆電電池只讀取 /sys/class/power_supply 中列出的屬性（電量、能量、電壓、電流、溫度、
循環次數、充電門檻、廠商與型號等），絕不讀 serial_number，也不讀含序號的 uevent；
UPower 只逐一讀取剩餘時間、充滿時間等需要的屬性，不讀序號或裝置路徑。
筆電的歷史紀錄只有時間、電量、整機耗電、是否接電與是否充電中。

系統監控頁只讀取需要的數值，而且只在頁面顯示時讀取，都不寫入檔案或日誌：
- 各 App 的用量只讀程序群組目錄名稱（App 代號）、累計 CPU 時間與記憶體，
  不讀任何程序的命令列、環境變數或開啟的檔案；名稱與圖示取自已安裝的桌面檔。
- 磁碟 SMART 透過系統的磁碟服務逐一讀取健康度、溫度、通電時間與讀寫量等屬性，
  不讀序號、WWN 或其他識別碼；磁碟服務的物件路徑只在記憶體中使用。
- 主要網路介面的 IPv4 只顯示在視窗裡，不寫入日誌、模擬測試結果或 --dump。

--dump 只輸出硬體種類摘要（項目名稱、類型、可讀的屬性名稱、是否有充電門檻等），
不含讀值、序號、UUID、MAC 位址、IP、主機名稱或家目錄與掛載路徑，也不寫任何檔案。
--preview 示範模式只用記憶體中的示範資料，不讀寫設定、歷史或裝置別名。

Solaar 完整 CLI 輸出只在查詢程序及解析期間存在於記憶體，
不寫入看板日誌、快取檔或發布產物。看板只保留電量、時間及本機匹配所需路徑。
Solaar 自己的個人設定也不屬於專案發布內容。
